## Dependency notes

- No plan logically depends on another — all five fix independent bugs.
- **File overlap, not dependency**: plans 001, 002, and 003 all touch
  `cmd/server/httpapi.go` and/or `cmd/server/broker.go`/`session.go`. If
  executed in the same working tree back-to-back, rebase/merge carefully
  between them to avoid clobbering each other's edits — but they can also
  be executed in parallel on separate branches and merged independently,
  since they touch different functions within those shared files.
- Plans 004 and 005 both touch the inbound-RTCP-trust surface
  (`internal/voip/call/callmanager_rtcp.go`'s `handleInboundRtcp` and what
  it calls into) but modify different files (004:
  `internal/voip/call/callmanager_rtcp.go`; 005:
  `internal/voip/media/{srtp,srtcp}.go`) — no file conflict, but a
  reviewer assessing "is inbound RTCP now trustworthy end-to-end" should
  look at both together.
- Plans 004 and 005 both touch code with **uncommitted local changes** on
  the current branch (`callmanager_rtcp.go` for 004, `srtcp.go` for 005) —
  their drift checks are written against the working tree, not just the
  base commit `3d2279e`. If that working tree is committed/changed before
  these plans execute, re-verify the "Current state" excerpts first.
